# خطة تبسيط MoneyFen

الخطة دي مكتوبة عشان موديل تاني (أو أي مطوّر) ينفذها خطوة خطوة من غير ما يعيد فهم البرنامج.
الكلام بالمصري، والأسماء التقنية بالإنجليزي زي ما هي في الكود.

> **نقطة الرجوع:** git tag `build-28` (commit `463309e`، اتعمل أوتوماتيك من CI مع الـ Release) — APK: build-28
> https://github.com/StrucTech/MoneyFen/releases/download/build-28/MoneyFen-28.apk

---

## 0) قواعد لازم تتمشى عليها في كل المراحل

1. **البرانش:** `claude/quirky-curie-zxoyfr` (أو برانش جديد من عنده). كل مرحلة = commit لوحدها.
   نقطة الرجوع لكل مرحلة = الـ tag `build-<رقم>` اللي CI بيعمله مع كل APK (اكتب رقمه في جدول "سجل المراحل" تحت).
   (لو تقدر تعمل tags بنفسك، اعمل كمان `simplify-pN-done`.)
2. **البيلد:** مفيش Android SDK محلي. الـ APK بيتعمل على GitHub Actions مع كل push
   (`.github/workflows/android.yml`) وبيتنشر Release اسمه `build-<رقم>`. أخطاء الكومبايل بتظهر في آخر اللوج تحت `ERRORS`.
3. **اختبارات المنطق:** أي منطق جديد (حسابات، قرارات أوتوماتيك) يتحط في `core/` كـ Kotlin عادي ويتعمله test في
   `core/src/test/...`، وده بيشتغل محلي: `./gradlew :core:test` (أو على CI).
4. **ممنوع تلمس** `core/.../CibParser.kt` ولا منطق الرصيد `BalanceCalc` — دول متجربين على ٩٠٠ رسالة حقيقية.
5. **قاعدة البيانات:** أي تغيير = migration **إضافي بس** (ADD COLUMN / CREATE TABLE). ممنوع حذف أو تغيير نوع عمود.
   زوّد `version` في `AppDb.kt` واكتب `Migration(n, n+1)`. البيانات القديمة لازم تفضل تشتغل.
6. **مفيش خاصية تتشال.** التبسيط = إخفاء/ترتيب/اختصار، مش حذف. كل حاجة قديمة لازم تفضل موجودة (ولو تحت "متقدم").
7. **الحفظ من Dialog:** أي حفظ بيحصل وبعده الـ dialog بيتقفل لازم يتعمل على `ctx.app.appScope.launch { ... }`
   مش `rememberCoroutineScope()` (كان فيه bug بسبب كده — الحفظ كان بيتلغي).
8. **اللغة:** كل نص يتكتب بـ `tr("English", "عربي")` (موجودة في `ui/Common.kt`).
9. **الريبو Public:** ممنوع تحط أي بيانات حقيقية (أرقام كروت، أسماء، رسايل) في الكود أو التستات.

## 1) خطة الرجوع (Rollback)

### أ) مفتاح "الواجهة القديمة" (أهم حاجة — اعمله في المرحلة 1 قبل أي تغيير)
- ضيف في `data/Prefs.kt`:
  ```kotlin
  var simpleUi: Boolean   // default true
  ```
- كل شاشة جديدة/متغيرة تتعمل **جنب** القديمة مش مكانها:
  `HomeScreen` القديمة تفضل زي ما هي، والجديدة `HomeScreenSimple`، وفي `MainActivity`:
  ```kotlin
  composable("home") { if (repo.prefs.simpleUi) HomeScreenSimple(snap) else HomeScreen(snap) }
  ```
- في الإعدادات (أول حاجة تحت "متقدم"): سويتش **"الواجهة القديمة"** ⓘ.
- كده لو حاجة باظت، المستخدم يرجع للقديم من غير ما يمسح حاجة.

### ب) الرجوع لنسخة أقدم من الأبلكيشن
⚠️ أندرويد مش بيسطّب نسخة رقمها أقدم فوق الأحدث، وقاعدة البيانات الأحدث مش بتفتح على كود أقدم. فالرجوع لازم يبقى كده:
1. من الإعدادات ← النسخ الاحتياطي: **Backup now** على Supabase **و** **Export** ملف JSON.
2. امسح الأبلكيشن (Uninstall).
3. سطّب النسخة القديمة (مثلاً build-28 من اللينك فوق).
4. الإعدادات ← النسخ الاحتياطي ← **Import** الملف أو **Restore** من Supabase.
   (الـ import بيتجاهل أي حقول جديدة مش يعرفها — `ignoreUnknownKeys = true` في `Backup.kt` — فالبيانات بترجع.)

**لازم تعمله:** أول ما النسخة الجديدة تفتح بعد update فيه migration، اعمل backup أوتوماتيك لملف داخلي
(`filesDir/pre-migration-<version>.json`) عن طريق `BackupJson.export`. وضيف في شاشة النسخ الاحتياطي زرار
"استرجع نسخة ما قبل التحديث" ⓘ.

### ج) الرجوع في الكود
- كل مرحلة ليها tag من CI: `build-<رقم>` (سجّله في "سجل المراحل").
- للرجوع عن مرحلة: `git revert <commits المرحلة>` وpush ← CI يطلع APK جديد. **متعملش force push.**
- لو مرحلة فيها migration واترجعت في الكود: سيب الـ migration والعمود (مش مشكلة لو مش مستخدم) — متمسحش عمود.

## 2) علامة ⓘ لكل حاجة (بتتطبق على كل المراحل)

### المكوّن
اعمل ملف `ui/Help.kt`:
```kotlin
/** أيقونة ⓘ صغيرة؛ الضغط عليها يفتح شرح قصير بالمصري/الإنجليزي. */
@Composable fun InfoTip(key: String, modifier: Modifier = Modifier)

object HelpTexts {
    // key -> (English, عربي). كل شرح 1–3 سطور، بكلام بسيط + مثال بأرقام لو ينفع.
    val items: Map<String, Pair<String, String>>
}
```
- `InfoTip` = `IconButton` صغير (18dp) بأيقونة `Icons.Outlined.Info`، والضغط يفتح `AlertDialog` (أو BottomSheet) فيه العنوان والشرح وزرار "تمام".
- لو المفتاح مش موجود في `HelpTexts` → متظهرش الأيقونة (عشان مفيش ⓘ فاضية).
- ضيف `ClickRow(..., help = "key")` و`SectionCard(..., help = "key")` و`SwitchRow(..., help = "key")` و`LabelValue(..., help = "key")`
  كـ parameter اختياري يحط الـ ⓘ جنب العنوان.

### القاعدة
**كل** عنوان كارت، **كل** رقم محسوب، **كل** سويتش في الإعدادات، **كل** زرار مش واضح من اسمه → ليه ⓘ.

### الشروحات المطلوبة (اكتبها كلها في `HelpTexts`)
| key | الشرح (عربي) |
|---|---|
| `today` | المسموح تصرفه النهارده. بيتحسب الصبح: (اللي معاك تصرفه ÷ الأيام لحد المرتب). ثابت طول اليوم. |
| `fromTomorrow` | لو صرفت أكتر/أقل النهارده، ده اللي هيبقى مسموح كل يوم من بكره. |
| `canSpend` | معاك تصرف = فلوس حساباتك + اللي ليك عند الناس (لو مفعّل) − المتحوّش − مديونية الكريديت. |
| `saved` | المتحوّش: فلوس محجوزة في حصّالاتك. لسه في حسابك بس مش محسوبة في "معاك تصرف". |
| `owedToMe` | ليك عند الناس: مصاريف دفعتها لحد وهيرجعهالك. |
| `cardDebt` | اللي عليك للكريديت = الحد − المتاح (من رسالة البنك). |
| `netWorth` | صافي الثروة = كل اللي تملكه (حسابات، كاش، دهب، صناديق…) − كل اللي عليك. |
| `netWorthChips` | دوس على نوع عشان تضيفه أو تشيله من حساب الثروة. |
| `decide` | معاملات محتاجة منك كلمة: مصروف ليك ولا لحد؟ فلوس داخلة دخل ولا سداد؟ |
| `alwaysThis` | البرنامج هيعمل نفس الاختيار لوحده مع نفس الاسم بعد كده. تقدر تلغيها من القواعد. |
| `forMe` / `forSomeone` / `betweenMine` | صرف ليا = مصروف عادي. لحد هيرجعهولي = مش مصروف، بيتسجل إنه ليك عنده. بين حساباتي = نقل فلوس، مش مصروف. |
| `income` / `repayment` / `notIncome` | دخل = بيتحسب في دخلك ونسبة التحويش. سداد = بيقلل اللي ليك عند الشخص. مش دخل = فلوس داخلة وخلاص. |
| `jars` | الحصّالات: فلوس بتحجزها لهدف. بتفضل في حسابك بس البرنامج مش بيحسبها معاك تصرف. |
| `salaryDay` | الشهر في البرنامج بيبدأ يوم نزول المرتب، مش يوم ١. |
| `savePercent` | لما المرتب ينزل البرنامج هيقترح تحوش النسبة دي منه. |
| `incomeSources` | اختار مين اللي فلوسه دخل حقيقي (المرتب أوتوماتيك). أي تحويل تاني مش بيتحسب دخل. |
| `ipnFee` | رسوم انستاباي: ٠٫١٪ من المبلغ، أقل حاجة ٠٫٥ وأقصى ٢٠ جنيه. بتتسجل معاملة لوحدها. |
| `reviewThreshold` | البرنامج مش هيسألك على مصاريف الكريديت غير لو التاجر جديد أو المبلغ أكبر من ده. |
| `livePrice` | سعر الدهب/الصندوق بيتحدث من النت لوحده (كل ما تفتح وكل ٦ ساعات). |
| `oldUi` | ترجعك للشكل القديم للبرنامج من غير ما يتمسح أي حاجة. |
| … | **ضيف key لكل حاجة جديدة تعملها.** |

**معيار القبول:** افتح كل شاشة واتأكد إن كل كارت/سويتش/رقم محسوب ليه ⓘ وبيفتح شرح مفهوم.

## 3) المراحل

### المرحلة 1 — البنية: مفتاح الواجهة + ⓘ + backup قبل الـ migration
**الملفات:** `data/Prefs.kt`، `ui/Help.kt` (جديد)، `ui/Common.kt`، `ui/MainActivity.kt`، `ui/SettingsScreens.kt`، `MoneyFenApp.kt`.
- `prefs.simpleUi` + سويتش "الواجهة القديمة".
- `InfoTip` + `HelpTexts` + parameter `help` في المكونات المشتركة.
- auto-backup قبل الـ migration (قسم 1-ب).
**القبول:** السويتش بيبدّل بين القديم والجديد (لسه الاتنين زي بعض)؛ ⓘ بتظهر وبتفتح شرح.

### المرحلة 2 — الرئيسية: رقم واحد كبير
**الملفات:** `ui/HomeScreenSimple.kt` (جديد)، `ui/ReviewUi.kt` (إعادة استخدام `SafeCard`/`DailyBlock` كأجزاء).
الترتيب من فوق لتحت:
1. كارت **"محتاج قرارك (n)"** — يظهر بس لو فيه حاجة (المرحلة 3).
2. **"تقدر تصرف النهارده"** رقم كبير ⓘ`today` + سطر: "من بكره X/يوم · لحد المرتب Y · Z يوم".
3. كارت **"معاك تصرف"** ⓘ`canSpend` — **مطوي** (يفتح بسهم): التفاصيل الحالية من `SafeCard`.
4. **"صافي الثروة"** ⓘ`netWorth` — مطوي، جواه الـ chips.
5. **"حساباتي"** — قايمة مختصرة (اسم + رقم)، الضغط يفتح الحساب.
6. الأسعار — سطر واحد صغير (دهب ٢١ · دولار · آخر تحديث)، الضغط يفتح الكارت الكامل.
- حالة الطي محفوظة في `prefs` (`collapsed_<card>`).
**القبول:** أول شاشة فيها ≤ ٣ أرقام ظاهرين من غير ما تفتح حاجة.

### المرحلة 3 — "محتاج قرارك": مكان واحد لكل الأسئلة
**الملفات:** `ui/DecideScreen.kt` (جديد)، `data/Repository.kt`، `data/Entities.kt` (+migration)، `ui/ReviewUi.kt`.
- شاشة/كروت ورا بعض لكل `needsReview`، كل كارت: الاسم، المبلغ، الحساب، التاريخ + زراير كبيرة:
  - **مصروف:** `صرف ليا` · `لحد هيرجعهولي` · `بين حساباتي` · `تقسيم…` (يفتح `ReviewDialog` الحالي)
  - **فلوس داخلة:** `دخل` (يفتح اقتراح التحويش في نفس الكارت) · `سداد فلوس ليا` · `مش دخل`
- تحت الزراير: ☑️ **"اعمل كده دايماً مع (الاسم)"** ⓘ`alwaysThis`.
- **الـ"دايماً"** = `RuleEntity` جديد: ضيف عمود `autoAction: String?` (migration ADD COLUMN) بقيم
  `MINE | REPAID | INTERNAL | INCOME | NOT_INCOME`. عند وصول رسالة جديدة، لو فيه rule بـ `autoAction`
  ينفّذه بدل `needsReview = true` (في `insertParsed`). ونفّذه كمان على المعاملات القديمة المعلقة لنفس الاسم.
- المنطق اللي بيختار الأكشن يتحط في `core` (`DecisionRules`) + test.
- قواعد "دايماً" تظهر في شاشة القواعد بعلامة 🤖 وينفع تتمسح.
**القبول:** تختار "دايماً" مرة لتالبات ← أي مصروف تالبات جديد ميسألش. تختار "دخل دايماً" لعميل ← يتحسب دخل ويقترح التحويش بس.

### المرحلة 4 — أسئلة أقل
**الملفات:** `data/Prefs.kt`، `data/Repository.kt` (`shouldReview`)، `core` (منطق + test).
- `prefs.reviewThreshold` (default 1000): مصروف الكريديت يتسأل عليه بس لو **(التاجر أول مرة)** أو **(المبلغ ≥ الحد)**.
  "أول مرة" = مفيش قبل كده معاملة بنفس `party` على نفس الحساب.
- **حصّالات بتتظبط لوحدها:** بعد أي تغيير رصيد/حجز، لو `free(حساب) < 0` وفيه حساب كاش/تاني free عنده موجب،
  انقل الفرق أوتوماتيك بـ `moveGoalBetween` (من أكبر حصّالة في الحساب السالب للحساب اللي فيه فلوس) وسجّلها في السجل.
  تتقفل/تتفتح بسويتش ⓘ.
**القبول:** ٢٠ مصروف تالبات تحت ١٠٠٠ ميطلعش ولا سؤال؛ مصروف عند تاجر جديد يطلع سؤال.

### المرحلة 5 — "الحصّالات" بدل أهداف + تحويش + تقسيم
**الملفات:** `ui/PlanScreen.kt` (نسخة Simple جنبها)، `ui/JarsScreen.kt` (جديد). **مفيش تغيير في الداتا** — الحصّالة = `GoalEntity` زي ما هو.
- قايمة حصّالات: اسم، إيموجي، المبلغ، شريط تقدم لو ليها هدف.
- ٣ زراير بس لكل حصّالة: **حط** · **خد** · **⋯** (فيها: تعديل، نقل بين حسابات، السجل، امسح).
- اختيار الحساب في "حط/خد" مخفي: الافتراضي = الحساب اللي فيه أكبر free؛ يظهر بس في "⋯".
- "خطة الادخار" (النسبة/المبلغ الثابت، الميزانيات) تبقى كارت فوق الحصّالات، مطوي.
**القبول:** واحد عمره ما شاف البرنامج يقدر يحط ويخد من حصّالة من غير ما يسأل.

### المرحلة 6 — الإعدادات: ٤ أقسام + متقدم
**الملفات:** `ui/SettingsScreens.kt` (نسخة Simple).
1. **المرتب والدخل:** بداية الشهر، نسبة/مبلغ التحويش، مصادر الدخل، اسألني عند المرتب.
2. **التصنيفات والميزانية:** التصنيفات، القواعد (بما فيها 🤖)، حد السؤال على الكريديت.
3. **الحسابات والاستثمارات:** "معاك تصرف" بيحسب إيه، الفلوس اللي ليك، أسعار لايف.
4. **النسخ الاحتياطي.**
5. **⚙️ متقدم (مطوي):** الواجهة القديمة، رسوم انستاباي، قوالب الرسايل (Regex)، أسماء المرسلين، سعر الدولار يدوي، فرق الدهب، تقسيم مصاريف الديبت، مسح كل حاجة.
- كل سويتش/حقل ليه ⓘ.
**القبول:** مفيش ولا إعداد اختفى (قارن بالقديمة سطر سطر)؛ الشاشة الأولى فيها ≤ ٥ عناوين.

### المرحلة 7 — شاشة المعاملة البسيطة + زرار "إيه ده؟"
**الملفات:** `ui/TransactionsScreen.kt` (`TxEditScreen` Simple).
- ظاهر: المبلغ، التصنيف، الملاحظة، والرسالة الأصلية (مطوية).
- **"المزيد"**: النوع، العملة، الحساب، التاريخ، الاستبعاد.
- زرار واحد **"إيه ده؟"** ⓘ يفتح نفس اختيارات المرحلة 3 حسب الاتجاه (بدل زراير: تقسيم/تحويش/يتحسب دخل/دايماً).
**القبول:** تعديل تصنيف معاملة = ضغطتين.

### المرحلة 8 — معالج أول مرة + كلام أبسط
**الملفات:** `ui/OnboardingWizard.kt` (جديد)، `HelpTexts`، كل الشاشات.
- معالج ٥ خطوات (كل خطوة فيها "تخطي"): استيراد الرسايل ← يوم المرتب ونسبة التحويش ← اختيار مصادر الدخل
  (قايمة من `incomeSources` بـ checkbox) ← رصيد الكاش ← دهب/صناديق (اختياري).
- يظهر لأول مرة، أو من الإعدادات "ابدأ الإعداد تاني".
- استبدال المصطلحات في النسخة البسيطة:
  Safe to spend → **معاك تصرف** · Reserved for goals → **متحوّش** · Owed to you → **ليك عند الناس** ·
  Goals → **حصّالات** · Net worth → **صافي الثروة** · Allowed per day → **تقدر تصرف النهارده**.
**القبول:** مستخدم جديد يوصل لرقم "تقدر تصرف النهارده" صح في أقل من ٣ دقايق.
